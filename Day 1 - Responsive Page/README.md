# Web Developer Portfolio

A clean, responsive web developer portfolio website built with pure HTML and CSS.

## 🚀 Features

- **4 Pages**: Home, About, Services, and Contact
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile
- **Sticky Navigation**: Header stays visible while scrolling
- **Active Link Highlighting**: Current page is highlighted in the navigation
- **Contact Form**: Ready-to-connect form layout for client inquiries
- **Modern UI**: Clean design with hover effects and smooth transitions

## 📁 Project Structure

```
HTML-task day1/
├── index.html        # Home page
├── about.html        # About page (skills & journey)
├── services.html     # Services page (offerings)
├── contact.html      # Contact page (form & info)
├── style.css         # Shared stylesheet
├── package.json      # Project dependencies

```

## 🛠️ Technologies Used

- **HTML5** — Semantic markup and structure
- **CSS3** — Flexbox, Grid, animations, responsive design
- **No frameworks** — Pure HTML & CSS for fast performance

## 📄 Pages Overview

| Page      | Description                                      |
|-----------|--------------------------------------------------|
| Home      | Hero section with introduction and key services  |
| About     | Skills, technologies, and developer journey      |
| Services  | Detailed list of web development offerings       |
| Contact   | Contact information and project inquiry form     |

## 🖥️ How to Use

1. Open `index.html` in any modern web browser
2. Navigate between pages using the header links
3. Customize the content, colors, and styles to match your brand

## 🎨 Customization

- **Colors**: Edit `style.css` to change the color scheme (primary: `#fecbca`, dark: `#1a1a1a`)
- **Content**: Edit text directly in each HTML file
- **Logo**: Change the logo text in the `.logo` section of each page

## 📱 Responsive Breakpoints

- **Desktop**: > 768px
- **Tablet**: 481px – 768px
- **Mobile**: ≤ 480px
