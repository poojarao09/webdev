# BeautiCare - Responsive Web Design

![BeautiCare Preview](./images/webpage.png) *(Note: Replace with your actual preview screenshot if desired)*

Welcome to the **BeautiCare** landing page! This is a beautifully crafted, single-page responsive website designed for a modern luxury spa and skincare clinic.

## 🌟 Features

- **Responsive Design**: Adapts seamlessly to all screen sizes (Desktop, Tablet, and Mobile) using CSS Media Queries.
- **Modern Aesthetics**: Utilizes **Glassmorphism** for the sticky navigation bar, soft gradients, and elegant CSS hover animations.
- **Layout Techniques**: Built with **CSS Grid** for the services section and **Flexbox** for the alignment of the hero and navigation sections.
- **Mobile Menu**: Includes a custom JavaScript-powered hamburger menu for smaller screens.
- **Smooth Scrolling**: Implements smooth anchor scrolling (`scroll-behavior: smooth`) for seamless page navigation.

## 🛠️ Built With

- **HTML5**: Semantic tags and clean structure.
- **Vanilla CSS3**: Custom properties (CSS variables), keyframe animations, `@media` queries.
- **Vanilla JavaScript**: Lightweight DOM manipulation to toggle the mobile navigation menu and apply scroll effects.

## 🚀 How to Use

1. Simply open the `index.html` file in any modern web browser (Google Chrome, Firefox, Safari, Edge).
2. Alternatively, if you use VS Code, you can right-click the `index.html` file and select **"Open with Live Server"** to view it with hot-reloading.

## 💡 Key Learnings

This project demonstrates the power of:
- **CSS Variables `:root`**: To easily manage and update the entire color theme.
- **Grid Auto-Fit & Minmax**: `grid-template-columns: repeat(auto-fit, minmax(320px, 1fr))` creates a responsive grid without needing excessive media queries.
- **Backdrop-Filter**: Providing the frosted glass effect in the fixed navigation bar.
